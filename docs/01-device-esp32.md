# 디바이스 연동 (ESP32)

## 개요

ESP32 보드와 서버가 통신하여 에어컨을 원격으로 제어하고, 센서 데이터를 수집한다.

## 요구사항

- ESP32 ↔ 서버 통신 (MQTT 또는 HTTP)
- 에어컨 전원 On/Off 제어
- 에어컨 온도/모드(냉방·제습·송풍 등) 원격 제어
- 온습도 등 센서 데이터 주기적 수집
- 디바이스 온라인/오프라인 상태 모니터링
- 디바이스 등록/삭제 (사용자가 자신의 ESP32 보드를 시스템에 등록)

## 결정 필요 사항

- 통신 프로토콜: MQTT vs HTTP (polling/webhook)
- 에어컨 제어 방식: 적외선(IR) 송신 vs 스마트 플러그/릴레이 등 하드웨어 구성
- 센서 데이터 수집 주기
- 디바이스-사용자 매핑 방식 (등록 코드, QR, 시리얼 번호 등)
