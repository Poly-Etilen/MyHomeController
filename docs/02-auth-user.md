# 사용자/인증

## 개요

사용자가 로그인하여 자신의 디바이스를 등록하고 관리할 수 있도록 한다.

## 요구사항

- 로그인 (이메일/비밀번호, OAuth2 Google 소셜 로그인)
- 사용자별 디바이스 등록/조회/삭제
- 디바이스 공유 (가족 등 여러 사용자가 같은 디바이스를 OWNER/MEMBER 역할로 공유 — [07-erd.md](./07-erd.md)의 `DEVICE_MEMBERS` 참고)
- 마이페이지 (프로필, 등록 디바이스 목록)

## 결정 필요 사항

- 단일 사용자용인지 멀티 테넌트(여러 가구/사용자)를 지원할지
- `DEVICE_MEMBERS.role` 외 세부 권한(제어만/조회만 등) 필요 여부
