# AI 리포트

## 개요

수집된 센서/제어 데이터를 기반으로 AI가 사용 패턴을 분석한 리포트를 자동 생성한다.

## 요구사항

- 일간/주간 사용 패턴 자동 분석 리포트 생성
- 온도 변화 대비 냉방 효율 분석, 절약 팁 제안
- 이상 패턴 감지 (예: 장시간 가동인데 온도 변화 없음 등)
- 리포트 조회 화면 (과거 리포트 목록/상세)

## 결정 필요 사항

- 사용할 AI 모델/방식 (LLM 프롬프트 기반 vs 규칙 기반 분석 후 요약)
- 리포트 생성 주기 및 트리거 (배치 스케줄 vs 사용자 요청 시)
- 분석에 사용할 데이터 범위 (온습도, 가동 시간, 전력 추정치 등)
